## 🇺🇸 English

### About the Project

RWK CLIENT is an independent Minecraft Java Edition launcher under development, built with C# and WPF for Windows.

The project aims to provide a modern, customizable launcher focused on Minecraft PvP.

### Features

- Custom desktop launcher interface
- Microsoft account authentication using Device Code Flow (in testing)
- Account management interface
- Planned Minecraft Java Edition 1.8.9 support
- Planned PvP customization features

### Development Status

**Alpha — Under Development**

Microsoft authentication is being tested. Xbox Live and Minecraft Services authentication is currently blocked pending application approval.

Minecraft launching functionality has not yet been implemented.

### Security

RWK CLIENT uses Microsoft's official authentication process and does not request or collect Microsoft account passwords.

## 🇧🇷 Português Brasileiro

### Sobre o Projeto

O RWK CLIENT é um launcher independente para Minecraft Java Edition, desenvolvido em C# e WPF para Windows.

O projeto tem como objetivo oferecer uma experiência moderna e personalizável, com foco em jogadores de Minecraft PvP.

### Funcionalidades

- Interface personalizada do launcher
- Autenticação Microsoft por código (em testes)
- Interface de gerenciamento de contas
- Suporte planejado ao Minecraft Java Edition 1.8.9
- Personalizações para PvP planejadas

### Estado do Desenvolvimento

**Alpha — Em desenvolvimento**

A autenticação Microsoft está em fase de testes. A integração com Xbox Live e Minecraft Services ainda depende da aprovação do aplicativo.

A funcionalidade de iniciar o Minecraft ainda não foi implementada.

### Segurança

O RWK CLIENT utiliza o processo oficial de autenticação da Microsoft e não solicita nem coleta senhas das contas Microsoft.
